# مقرأة رحاب القرآن الإلكترونية 📖
### المنظومة التعليمية المتكاملة لتعليم وحفظ وتجويد القرآن الكريم بالسند المتصل

منصة تعليمية إسلامية حديثة، مصممة بأعلى معايير الأمان وقابلية التوسع (Production-Ready)، مع دعم كامل للغة العربية والاتجاه من اليمين إلى اليسار (RTL)، وتصميم متجاوب لجميع الأجهزة (الهواتف، الأجهزة اللوحية، والشاشات الكبيرة).

---

## ✨ المميزات الرئيسية
- **نظام مستخدمين وصلاحيات متقدم (RBAC)**: يدعم 6 أدوار وظيفية مستقلة (طالب، معلم، مشرف أكاديمي، مدير نظام، ولي أمر، مراجع جودة).
- **مصادقة متعددة القنوات**: الدخول بالبريد الإلكتروني، أو رقم الهاتف والواتساب، أو حساب Google الرسمي.
- **تشفير الصلاحيات (Custom Claims)**: التحقق من الصلاحيات الحساسة عبر الخادم وقواعد Firestore دون الاعتماد على الواجهة.
- **عزل أمني تام**: قواعد أمان مشددة في Cloud Firestore تمنع أي مستخدم من الوصول لسجلات أو تلاوات غيره.
- **منهج تجويد تفاعلي متدرج**: نظام فتح مشروط (🟢 مفتوح، ✅ مكتمل، 🔒 مقفل) باجتياز الاختبارات ورصد الدرجات تلقائياً.
- **تسجيل واستماع صوتي نقي**: تسجيل التسميع الحي وإرساله للشيخ مع توجيه صوتي وتجويدي معتمد.
- **التحقق من البيانات**: استخدام مكتبة Zod للتحقق الصارم من صحة المدخلات.
- **إدارة الحالة وجلب البيانات**: TanStack Query لتخزين مؤقت واسترجاع سلس للبيانات.

## 🛠️ التقنيات المستخدمة (Tech Stack)
| المجال | التقنية المستخدمة |
| :--- | :--- |
| **واجهة المستخدم** | React 19 + TypeScript + Vite |
| **التصميم والأنماط** | Tailwind CSS v4 + خطوط Tajawal و Amiri و Noto Kufi Arabic |
| **قواعد البيانات والسحابة** | Cloud Firestore + Firebase Storage |
| **المصادقة والأمان** | Firebase Authentication + Custom Claims + Firestore Rules |
| **الخادم والعمليات الخلفية** | Node.js + Express Server Runtime على Cloud Run |
| **التحقق وإدارة النماذج** | Zod + React Hook Form |
| **جلب وتخزين البيانات** | TanStack Query v5 |
| **الاختبارات** | حزمة اختبارات مؤتمتة لقواعد الأمان والـ RBAC |

## 🚀 التشغيل المحلي (Getting Started)

1. **تثبيت الاعتماديات**:
   ```bash
   npm install
   ```

2. **ملف البيئة**:
   انسخ ملف `.env.example` إلى `.env` واضبط المتغيرات العامة:
   ```bash
   cp .env.example .env
   ```

3. **تشغيل الخادم وخادم التطوير**:
   ```bash
   npm run dev
   ```
   يفتح التطبيق على المنفذ `http://localhost:3000`.

4. **تشغيل الاختبارات الأمنية**:
   ```bash
   npx tsx scripts/test-firestore-security.ts
   ```

5. **فحص الأنواع البرمجية (Type Check)**:
   ```bash
   npm run lint
   ```

6. **بناء نسخة الإنتاج (Production Build)**:
   ```bash
   npm run build
   ```
